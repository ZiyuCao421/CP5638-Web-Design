# CP5638 Web Design

This repository is an academic development portfolio for CP5638 Web Design. It brings together weekly practical work, workshop material, and the completed Vcare Opticals website with its supporting assessment report.

## Live project

[Visit the Vcare Opticals website](https://jcu-web-design-5638-a3-ziyucao.netlify.app)

The website presents an optometry practice in Razole, Queensland. It provides service information, eye-health guidance, practice details, booking prompts, and contact options.

## Vcare Opticals website

### Key features

- A responsive, multi-page HTML5 website for mobile, tablet, and desktop screens.
- Service and eye-health information supported by external articles and research links.
- A contact page with a location map, booking call-to-action, email and telephone details, WhatsApp access, and a fax-number copy button.
- Client-side JavaScript for form validation and interactive contact functions.
- Custom visual content and page-specific design treatments for eye care, technology, and contact information.
- Cloudflare Web Analytics integration to support post-launch traffic and performance review.

### Built with

- HTML5
- CSS3
- JavaScript
- Google Maps embed
- Cloudflare Web Analytics
- Netlify hosting

## Run locally

No installation or build process is required.

1. Clone or download this repository.
2. Open the `full page` folder.
3. Open `index.html` in a browser, or run the folder through a local development server such as VS Code Live Server.

## Quality checks

The final website was reviewed across mobile, tablet, and desktop widths. Navigation, internal and external links, forms, contact actions, map access, and article links were checked. HTML/CSS validation was also completed using the W3C validation services.
